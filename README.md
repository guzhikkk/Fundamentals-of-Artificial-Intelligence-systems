# Fundamentals-of-Artificial-Intelligence-systems


A collection of laboratory assignments for the **"Fundamentals of Artificial Intelligence Systems"** course. Each lab is stored in its own folder and contains the original Jupyter Notebook provided by the instructor along with any accompanying data files.

## About

The repository contains solutions and notes for lab assignments covering core topics of artificial intelligence systems, including machine learning fundamentals and classical optimization algorithms.
