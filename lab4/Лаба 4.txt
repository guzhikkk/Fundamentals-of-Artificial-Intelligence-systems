Разберем теоретическую суть, алгоритм действий и ключевые нюансы каждого задания.
Задание 1. Разбиение на обучающую и тестовую выборки (Train/Test Split)
Теоретическая суть: В машинном обучении нельзя оценивать модель на тех же данных, на которых она обучалась (это приведет к переобучению / overfitting). По этой причине датасет делят на две части:
	•	Train (обучающая): фиксирует закономерности и настраивает параметры модели.
	•	Test (тестовая): имитирует новые, неизвестные модели данные и оценивает ее реальное качество.
Ключевые нюансы задачи:
	1.	Случайность и перемешивание: Данные в исходном списке могут быть отсортированы (например, сначала идут все класс 0, затем класс 1). Если просто отрезать первые X\%, модель вовсе не увидит часть данных. По этой причине перед разделением данные обязательно перемешивают.
	2.	Неизменяемость исходного списка (deepcopy): По умолчанию функция shuffle меняет список «на месте» (in-place). Если передать оригинал, исходные данные изменятся. Чтобы избежать этого, создают глубокую копию списка через deepcopy.
	3.	Округление вниз (floor): Размер выборки в штуках должен быть целым числом. Если от 105 элементов взять 70\%, получится 73.5. Инструкция требует округлять количество элементов вниз до 73.
Задание 2. Кросс-валидация (k-Fold Cross-Validation)
Теоретическая суть: Обычное разбиение train/test зависимо от того, как именно случайно легли данные. На одном «удачном» разбиении модель может показать высокую точность, а на другом — низкую. Кросс-валидация решают эту проблему:
	•	Данные делятся на k равных частей (фолдов).
	•	Проводится k итераций.
	•	На i-й итерации i-й фолд становится тестовым, а остальные k-1 фолдов — обучающими.
	•	Результаты всех k прогонов усредняются.
Ключевые нюансы задачи:
	1.	Синхронное перемешивание признаков и ответов (zip): Данные состоят из объектов X (data_x) и целевых меток y (data_y). Если перемешать data_x отдельно от data_y, связи между объектом и его правильным ответом разрушатся. Чтобы сохранить парность, их «сшивают» с помощью zip, перемешивают полученные пары и разворачивают обратно.
	2.	Единый shuffle: Ограничение задания требует вызвать shuffle у генератора строго один раз, поэтому создание пар перед перемешиванием — единственно верный путь.
	3.	Метрика MAE (Mean Absolute Error): Оценка качества рассчитывается как средний модуль отклонения предсказания от истинного значения \frac{1}{n} \sum \vert{}y_i - \hat{y}_i\vert{}.
Задание 3. Погрешность оценки качества (Закон больших чисел и ЦПТ)
Теоретическая суть: В реальной жизни размер подвыборки ограничён. Данный номер наглядно демонстрирует, как размер выборки влияет на разброс (дисперсию) метрики качества.
	•	Если брать маленькие выборки (например, по 100 объектов из полного набора), оценка точности на каждой отдельной выборке будет отклоняться от «истинной» точности на всем датасете.
	•		•	Согласно Центральной Предельной Теореме (ЦПТ), если многократно извлекать случайные выборки и считать по ним среднюю ошибку, распределение этих средних будет стремиться к нормальному (симметричному колоколу).
Ответы на вопросы задания:
	•	Выбор графика: Из представленных гистограмм нормальному распределению с поджатыми хвостами отвечает График C.
	•	Смещение (Bias): Модуль разности между истинной точностью на всей популяции и средним арифметическим по 10 000 выборкам проверяет несмещенность оценки (средняя оценка по подвыборкам близка к истинному значению).
	•	Стандартное отклонение (Spread): Формула разброса — это стандартное отклонение (квадратный корень из дисперсии). Она показывает, насколько сильным может быть случайный «люфт» метрики при оценке всего по 100 объектам.
Задание 4. Бутстрап (Bootstrap)
Теоретическая суть: Бутстрап — метод оценки неопределенности (например, построения доверительных интервалов) без знания исходного распределения.
	•	Главное отличие от обычного сэмплирования из Задания 3: выборки генерируются с возвращением/повторениями (choices вместо sample).
	•	Размер каждой бутстрап-выборки равен размеру исходного датасета N.
Алгоритм построения доверительного интервала:
	1.	Генерируется 10\,000 бутстрап-выборок размера N.
	2.	На каждой выборке считается ошибка (MAE).
	3.	Полученные 10\,000 значений ошибок сортируются по возрастанию.
	4.	С концов полученного отсортированного списка отсекается заданный процент крайних значений с помощью функции cut_on_edges (например, по 2.5\% с каждого края для 95%-го доверительного интервала).
	5.	Первый и последний элемент оставшегося списка образуют границу доверительного интервала.
