Работа со случайностью в Python
В Python существует встроенный модуль random, в котором содержатся функции для работы со случайностью.
Импортировать модуль можно привычным образом:
import random
Модуль позволяет создать генератор случайных чисел, на основе которого в дальнейшем будут производиться случайные операции:
random_numbers_gen = random.Random()
Случайные числа
Теперь можно воспользоваться генератором, чтобы, например, получить случайное число в интервале от 0 до 1 с помощью функции random:
print(random_numbers_gen.random()) # 0.1775542516029539
print(random_numbers_gen.random()) # 0.5214716921291895
Если вы запустите этот же код у себя на компьютере, то сгенерированные значения получатся другими, потому что они являются случайными.
Случайные операции со списком
Перемешивание списка
С помощью генератора можно производить случайное перемешивание списка, воспользовавшись функцией shuffle:
l = [1, 2, 3, 4, 5, 6, 7]
random_numbers_gen.shuffle(l)
print(l) # [2, 1, 5, 7, 3, 4, 6]
Если ещё раз перемешать список, то результат получится другим:
random_numbers_gen.shuffle(l)
print(l) # [5, 3, 1, 6, 4, 2, 7]
Важно. shuffle меняет порядок элементов в исходном списке, который передаётся в функцию аргументом. Об этом нужно помнить, чтобы не изменить случайно исходный список, если вы не планировали это делать.
Случайная выборка
Генератор случайных чисел позволяет сгенерировать на основе переданного списка случайный набор из элементов этого списка. Он называется случайной выборкой.
Для генерации выборки нужно воспользоваться функцией sample:
l = [1, 2, 3, 4, 5, 6, 7]
sub_l = random_numbers_gen.sample(l, 3)
print(sub_l) # [3, 1, 5]
Функция sample на вход принимает список, на основе которого нужно произвести генерацию выборки, а также размер желаемой выборки.
Важно. Каждый элемент исходного списка будет встречаться в выборке не более одного раза. Такая выборка называется выборкой без повторений. Значит, функция sample на основе переданного списка элементов генерирует именно выборку без повторений.
Принцип генерации случайности
Любая случайность, порождённая компьютером, является искусственной, потому что наблюдать по-настоящему случайное явление в природе непросто.
Любые случайные операции, которые производит генератор случайных чисел, для нас выглядят случайными, но с алгоритмической точки зрения таковыми не являются. Генератор принимает на вход некоторое число seed и на его основе, согласно заложенным в генератор алгоритмам, моделирует случайное поведение:
seed = 0
random_numbers_gen = random.Random(seed)
Если значение seed не задавать, то компьютер сам подставит вместо него какое-то число. Например, возьмёт текущее время, преобразует его в число и будет использовать в качестве seed, то есть вручную задавать значение параметра не обязательно.
Однако если задавать конкретное значение seed, это позволяет воспроизводить результаты случайных действий:
l = [1, 2, 3, 4, 5, 6, 7]

random_numbers_gen = random.Random(0)
print(random_numbers_gen.sample(l, 3)) # [7, 4, 6]

random_numbers_gen = random.Random(0)
print(random_numbers_gen.sample(l, 3)) # [7, 4, 6]
В частности, на вашем компьютере код выше выведет те же самые значения.
Если при создании генератора не задавать параметр seed, то в разных случаях сгенерируются разные выборки:
random_numbers_gen = random.Random()
print(random_numbers_gen.sample(l, 3)) # [1, 6, 5]

random_numbers_gen = random.Random()
print(random_numbers_gen.sample(l, 3)) # [6, 4, 7]
Важно. Если в коде встречается несколько обращений к какому-то генератору случайных чисел с заданным значением seed, то при последующем перезапуске этих действий на новом генераторе с тем же самым seed результаты действий совпадут с теми, которые были изначально. То есть значение параметра seed фиксирует результат не одного конкретного действия с генератором случайных чисел, а всех действий с ним:
random_numbers_gen = random.Random(0)

print(random_numbers_gen.sample(l, 3)) # сгенерирует выборку [7, 4, 6]
print(random_numbers_gen.sample(l, 3)) # сгенерирует новую выборку [1, 3, 5]

random_numbers_gen = random.Random(0)

print(random_numbers_gen.sample(l, 3)) # сгенерирует ту же выборку,
                                       # что и в первый раз, [7, 4, 6]
print(random_numbers_gen.sample(l, 3)) # после генерации [7, 4, 6] сгенерирует то же,
                                       # что и раньше, [1, 3, 5]
Использование параметра seed в заданиях 
В общем случае задавать параметр seed для генератора случайных чисел не обязательно.
Однако в рамках заданий, в которых происходит работа со случайностью, вам будет необходимо использовать генераторы случайных чисел с заранее определённым значением параметра seed. Это сделано, чтобы соответствующие задачи можно было проверить с помощью тестов.

Задание 1 Разбиение на обучающую, валидационную и тестовую выборки
Разбиение данных на обучающую и тестовую выборки (или разбиение обучающей выборки на обучающую и валидационную выборку) обычно происходит случайным образом.
Алгоритм такой:
1.	Случайно перемешать массив имеющихся данных.
2.	Первые X% элементов полученного массива определить в обучающую выборку, а оставшуюся часть определить в тестовую выборку.
Реализуйте функцию train_test_split_solution, которая разбивает переданный список объектов на обучающую и тестовую выборку, согласно описанному выше алгоритму.
Аргументы функции train_test_split_solution:
•	data — список объектов, который нужно разделить на части;
•	train_frac — доля объектов, которые нужно отправить в обучающую выборку. Доля — число, находящееся в диапазоне от 0 до 1;
•	random_gen — генератор случайных чисел.
В результате работы функция train_test_split_solution должна возвращать пару списков: обучающая выборка и тестовая выборка.
На работу функции накладываются три условия:
1.	В результате работы функции исходный список data-объектов не должен измениться.
2.	В процессе работы функции вызов функции shuffle у генератора random_gen должен производиться только один раз.
3.	При определении числа элементов, которые попадут в обучающую выборку, округление должно происходить вниз.

Рекомендации по решению
Перемешивание какого-то списка с помощью функции shuffle полезно производить в его копии, чтобы не менять исходный список.
Для создания копии объекта в Python есть функция deepcopy, которая находится в модуле copy:
from copy import deepcopy
import random

l = [1, 2, 3]
l_new = deepcopy(l)

random_gen = random.Random()
random_gen.shuffle(l_new)

print(l) # исходный список не изменился — [1, 2, 3]
print(l_new) # перемешался только новый список — [2, 1, 3]
Чтобы округлить вещественное число вниз, в Python есть специальная функция floor из модуля math:
from math import floor

print(floor(1.7)) # выведет 1

Рекомендации по решению
Чтобы при перемешивании сохранить соответствие объектов из data_x значениям data_y, которые необходимо предсказать, нужно соединить объекты и значения в один список и перемешать его:

Здесь мы воспользовались функцией zip, которая в комбинации с функцией list делает из двух списков список пар соответствующих значений этих списков.
