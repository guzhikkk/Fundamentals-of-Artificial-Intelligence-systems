## Задание 1. Grid search

Реализуйте функцию `grid_search_solution`, которая принимает набор конфигураций модели линейной регрессии и находит лучшую из них с помощью алгоритма grid search. Конфигурация модели представляет собой набор факторов, используемых для предсказания заданной величины.

### Аргументы функции `grid_search_solution`

- `model` — модель линейной регрессии, для которой нужно подобрать оптимальную конфигурацию;
- `model_configs` — список конфигураций модели линейной регрессии. Каждая конфигурация — список номеров факторов, используемых для обучения модели. Например, если какой-то элемент `model_configs` равен `[0, 2, 6]`, то это значит, что для обучения модели с заданной конфигурацией нужно использовать только факторы с индексами `0`, `2` и `6`;
- `x_train` — список объектов обучающей выборки. Каждый объект представлен списком значений факторов;
- `y_train` — список значений предсказываемой характеристики для объектов из обучающей выборки. Значение на `i`-й позиции в списке соответствует `i`-му объекту обучающей выборки;
- `x_val` — список объектов валидационной выборки. Каждый объект представлен списком значений факторов;
- `y_val` — список значений предсказываемой характеристики для объектов из валидационной выборки. Значение на `i`-й позиции в списке соответствует `i`-му объекту валидационной выборки.

В качестве модели выступает модель линейной регрессии из библиотеки `sklearn`, прочитать о её использовании можно в соответствующей секции ниже.

Оценку точности модели с заданной конкретной конфигурацией необходимо производить с помощью функции `score_model`, которая оценивает точность переданной модели на заданной выборке по метрике «среднее отклонение от предсказанного значения».

В результате работы функция `grid_search_solution` должна возвращать пару значений:

1. Лучшая конфигурация из переданных.
2. Точность модели с данной конфигурацией на валидационной выборке.

Точность модели необходимо округлить до двух знаков после запятой с помощью функции `round_to_2`.

Заготовка для функции `grid_search_solution` уже реализована в блокноте с задачами этого модуля.

## Задание 3. Градиентный спуск

Реализуйте функцию `gradient_descent_solution`, которая производит поиск минимума заданной функции двух аргументов с помощью градиентного спуска.

Аргументом функции двух аргументов является список из двух значений — первого и второго аргументов функции. Пример работы такой функции:

```python
def f(x):
    """
    Функция f(x, y) = x ** 2 + 2 * y, которая вместо отдельных
    аргументов принимает список аргументов.
    """

    return x[0] ** 2 + 2 * x[1]
```

Градиент такой функции — это тоже функция двух аргументов. Она возвращает вектор из двух значений:

```python
def grad_f(x):
    """
    Градиент функции f(x, y) = x ** 2 + 2 * y, то есть функция,
    которая возвращает вектор [2 * x, 2].
    """

    return [2 * x[0], 2]
```

Список из двух значений можно интерпретировать как точку на плоскости. Поэтому в дальнейшем будем говорить, что любая функция двух аргументов принимает на вход «точку».

### Аргументы функции `gradient_descent_solution`

- `grad_f` — градиент функции двух аргументов, для которой необходимо найти минимум. Градиент — это функция, которая принимает на вход точку и возвращает вектор градиента в этой точке;
- `x_0` — стартовая точка, из которой запускается алгоритм градиентного спуска;
- `alpha` — коэффициент скорости обучения;
- `eps` — минимальное расстояние между текущей точкой градиентного спуска и следующей, при котором работа алгоритма останавливается.

В результате работы функция `gradient_descent_solution` должна возвращать координаты точки (список из двух значений), в которой достигается минимальное значение функции. Каждая координата должна быть округлена до двух знаков после запятой с помощью функции `round_to_2`.
